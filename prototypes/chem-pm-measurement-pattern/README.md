# CurioNest Measurement Worksheet Pattern Proof

Four-page A4 proof inspired by the instructional rhythm of Chem Pride worksheets: concise explanation, guided example, student attempt, and repair reflection. All wording and layout are original.

Build from the repository root:

```powershell
python prototypes/chem-pm-measurement-pattern/build.py
```

Outputs:

- `output/pdf/curionest-measurement-pattern-student.pdf`
- `output/pdf/curionest-measurement-pattern-tutor.pdf`

Both editions use identical page geometry. The tutor edition overlays answers and intervention notes without changing the page structure.
