# ChemPride-Based Chemistry Topic and Format Map

**สถานะ:** กฎฐานถาวรของสายการผลิต  
**วันที่ตัดสินใจ:** 2026-08-11  
**แหล่งฐาน:** https://chempride.weebly.com/

## ความหมายของคำว่า “ใช้เป็นฐาน”

ใช้ ChemPride เป็นฐานสำหรับ:

- แผนที่หัวข้อและลำดับการเรียนเคมี;
- จังหวะการใช้งานในห้องเรียนระดับกว้างเท่านั้น; โครงสร้างบังคับของ CurioNest ให้ยึด `complete-unit-instruction-standard.md` คือ Engage -> Teach -> Model -> Guided Practice -> Independent Practice -> Formative Check -> Mixed Review -> Summative Assessment;
- แนวคิดการแยกหนึ่งหัวข้อออกเป็นผลิตภัณฑ์หลายรูปแบบ;
- การจัดแพ็กนักเรียน คู่มือครู เฉลย และส่วนขยายเป็นสัดส่วน.

ChemPride มีสถานะ `benchmark_only` ไม่ใช่แหล่งเนื้อหาที่นำมาขายต่อ ห้ามคัดลอกหรือดัดแปลงโจทย์ คำอธิบาย เฉลย ภาพ โลโก้ ตาราง หน้าตา หรือลำดับหน้าเฉพาะของเว็บ ทุกผลิตภัณฑ์ต้องเขียนใหม่และมีเอกลักษณ์ของ CurioNest

## รูปแบบที่แตกออกจากแต่ละหัวข้อ

| กลุ่ม | รูปแบบผลิตภัณฑ์ | งานทางความคิดหลัก |
|---|---|---|
| Core learning | Scenario/Problem Analysis, Visual Guided Notes, Task Cards, Stations Circuit | เรียนแนวคิด ตัดสินใจ อธิบาย และฝึกหลายบริบท |
| Practice and engagement | Digital Self-Checking, Sorting/Matching/Domino, No-Lock Escape, Picture Reveal/Color-by-Code | ฝึกซ้ำ รับ feedback และตรวจความเข้าใจระหว่างเรียน |
| Assessment and transfer | Reading + CER, Quiz/Test A-B-Retake, Lab Practical, Project/Choice Board, Scavenger/Gallery, Spiral Review | ประเมิน ถ่ายโอนความรู้ และเชื่อมหลายทักษะ |

เป้าหมายคือ 10 รูปแบบขึ้นไปต่อหัวข้อ และมีโครงมาตรฐาน 14 รูปแบบ แต่ไม่จำเป็นต้องสร้างครบพร้อมกัน รูปแบบใหม่ต้องเปลี่ยนงานทางความคิดหรือสถานการณ์ใช้จริง ไม่ใช่นำคำถามเดิมไปจัดหน้าใหม่

## Pattern หน่วยสอนฐาน

เริ่มทุกหัวข้อด้วย proof 4 หน้าเพื่อตรวจภาษา ภาพ และงานพิมพ์ ก่อนขยายเป็นแพ็กใหญ่ แต่ proof ไม่ใช่สินค้าที่อ้างว่าเป็น complete unit:

1. เป้าหมายการเรียนและภาพใช้งานจริงที่จำเป็นต่อโจทย์
2. สรุปกะทัดรัด พร้อมภาพอุปกรณ์ แผนภาพ ตาราง หรือหลักฐานที่เหมาะสม
3. บทสอนและ worked example ตามด้วย Guided practice และ Independent practice พร้อมพื้นที่เขียนจริง
4. Visual evidence task พร้อม error/repair loop

สินค้าที่ใช้คำว่า Unit Pack ต้องมีบทสอนครบทุก lesson, formative check, mixed review, Unit Test A/B และ rationale key ตาม `complete-unit-instruction-standard.md` ต้องมี Student Edition และ Teacher Edition ที่ใช้ระบบภาพเดียวกัน เมื่อ proof ผ่าน content, rights, visual และ print QA แล้วจึงขยายเป็นหน่วยเต็ม

## กฎภาพถาวร

- วาง Visual Plan ระดับข้อ/หน้า ก่อนเขียนและจัดหน้า
- ถ้าโจทย์ต้องสังเกตอุปกรณ์ อันตราย สัญลักษณ์ โครงสร้าง อนุภาค หรือความสัมพันธ์เชิงพื้นที่ ต้องมีภาพที่เป็นหลักฐานจริง
- ใช้ภาพจากแหล่งฟรีที่อนุญาตใช้เชิงพาณิชย์และบันทึก URL ผู้สร้าง ใบอนุญาต และ attribution ใน manifest
- ห้ามใช้ภาพ AI และห้ามวาดภาพเลียนแบบด้วยโค้ดสำหรับงานใบงานชุดนี้
- ถ้าหาภาพที่มีสิทธิ์เหมาะสมไม่ได้ ให้สถานะงานเป็น `BLOCKED` ห้ามลดโจทย์เป็น text-only เพื่อให้ผ่าน QA
- ภาพตกแต่งไม่ทดแทนภาพที่ทำหน้าที่เป็นหลักฐานการเรียนรู้

## ลำดับผลิตมาตรฐาน

`topic map -> rights and source screen -> visual plan -> product brief -> 4-page proof -> student/tutor pair -> render every page -> QA -> pilot -> listing package -> certified -> publish`

ไฟล์นี้เป็น source of truth ของการเลือกหัวข้อและการแตก format หากเอกสารเก่าขัดกับไฟล์นี้ ให้ยึดไฟล์นี้และ `product-lines/instructional-visual-policy.md` เป็นหลัก
