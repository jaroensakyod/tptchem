# Product QA Checklist

- Product ID:
- Version/build hash:
- Reviewer/date:
- Decision: PASS / CONDITIONAL / FAIL

## Content

- [ ] Learning targets align to current pacing/standards
- [ ] Facts, units, calculations, labels, and safety statements verified
- [ ] Every prompt is original
- [ ] Ambiguous or alternate answers documented

## Answer key

- [ ] 100% of scorable items covered
- [ ] Numbering/version match
- [ ] Explanations address likely misconceptions
- [ ] Independent answer check completed

## Rights

- [ ] Source ledger complete
- [ ] Asset manifest complete
- [ ] No restricted content adapted commercially
- [ ] Attribution/TOU accurate
- [ ] Seller/brand is not presented as an instructional content reference
- [ ] Benchmark-only worksheets/sites are separated from buyer-facing authoritative sources

## Student and teacher use

- [ ] Directions pass cold-read
- [ ] Default U.S. market profile is explicit: American English, US Letter, U.S. grades, Name/Date/Class Period
- [ ] Timing is realistic
- [ ] Writing space is sufficient
- [ ] Differentiation works, not cosmetic
- [ ] Site/district policy caveats included where needed

## Visual and technical

- [ ] Visual plan covers every scored item, scenario, activity page, and repeated card type
- [ ] Every visual marked `required` is present in both student and teacher versions
- [ ] Every `no visual required` decision has a specific instructional justification
- [ ] Observation, equipment-identification, hazard-recognition, spatial, symbolic, and particle-level tasks do not rely on text alone
- [ ] Visual coverage count matches the source plan; missing required visuals make the decision `FAIL`
- [ ] Every instructional image has verified commercial-use rights and a manifest/source-ledger record
- [ ] No AI-generated or code-drawn substitute is used where the product policy requires free-source verified imagery
- [ ] All PDF pages rendered and inspected
- [ ] Editable file rendered and compared
- [ ] No clipping, overlap, missing glyph, blank page, or orphan heading
- [ ] Student response lines and teacher answers are mutually exclusive; no answer overlays a line, prompt, border, or image
- [ ] US Letter and printer-safe margins
- [ ] B&W readability checked
- [ ] Page numbers, titles, page count, and file names correct
- [ ] PDF reopens and text is extractable

## Listing

- [ ] Cover remains readable as a thumbnail
- [ ] Preview uses actual pages
- [ ] Description matches files, grade, duration, and page count
- [ ] No inflated page-count or outcome claim
