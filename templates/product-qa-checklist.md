# Product QA Checklist

- Product ID:
- Version/build hash:
- Reviewer/date:
- Decision: PASS / CONDITIONAL / FAIL

## Content

- [ ] Learning targets align to current pacing/standards
- [ ] Facts, units, calculations, labels, and safety statements verified
- [ ] Every prompt is original
- [ ] Ambiguous or alternate answers documented

## Answer key

- [ ] 100% of scorable items covered
- [ ] Numbering/version match
- [ ] Explanations address likely misconceptions
- [ ] Independent answer check completed

## Rights

- [ ] Source ledger complete
- [ ] Asset manifest complete
- [ ] No restricted content adapted commercially
- [ ] Attribution/TOU accurate

## Student and teacher use

- [ ] Directions pass cold-read
- [ ] Timing is realistic
- [ ] Writing space is sufficient
- [ ] Differentiation works, not cosmetic
- [ ] Site/district policy caveats included where needed

## Visual and technical

- [ ] All PDF pages rendered and inspected
- [ ] Editable file rendered and compared
- [ ] No clipping, overlap, missing glyph, blank page, or orphan heading
- [ ] US Letter and printer-safe margins
- [ ] B&W readability checked
- [ ] Page numbers, titles, page count, and file names correct
- [ ] PDF reopens and text is extractable

## Listing

- [ ] Cover remains readable as a thumbnail
- [ ] Preview uses actual pages
- [ ] Description matches files, grade, duration, and page count
- [ ] No inflated page-count or outcome claim
