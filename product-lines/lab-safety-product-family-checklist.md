# Lab Safety Product Family Checklist

Lab Safety ไม่ใช่สินค้าแบบเดียว เป้าหมายคือสร้างหลาย format ที่ให้นักเรียนทำงานทางความคิดต่างกัน และรวมเป็น bundle เมื่อแต่ละชิ้นผ่าน QA จริง

## Current release board

|---:|---|---|---|---|

## Bundle milestones

- [ ] Mini Bundle: เปิดเมื่อ Formats 1–4 ผ่าน QA และ human release gates
- [ ] Full Lab Safety Bundle: เปิดเมื่ออย่างน้อย 10 formats ผ่าน QA และมี product listing แยกครบ
- [ ] ห้ามโพสต์สินค้าซ้ำที่ต่างเพียงสีหรือย้ายคำถามเดิมไปอีก layout
- [ ] ทุก format ต้องมี buyer use case และ cognitive task ที่ต่างกันอย่างเห็นได้ชัด

## Immediate order of work

1. ปิด release gates ของ Scenario Analysis และ Task Cards
2. สร้าง buyer ZIP และ listing draft ที่ตรวจแล้วสำหรับสองสินค้านี้
3. อัปโหลดเป็น draft โดยยังไม่เปิดขาย แล้วตรวจหน้าร้าน
4. เปิดขายเมื่อ review/pilot ครบ
5. เริ่ม Lab Safety Stations เป็น Format 3
6. เมื่อ Format 3 ผ่าน QA จึงเริ่ม Visual Guided Notes เป็น Format 4
7. หลัง Formats 1–4 certified ให้สร้าง Mini Bundle

**Mandatory stop:** Steps 2–7 cannot begin while Scenario Analysis or Task Cards has a blocked instructional visual gate. Decorative cover/listing graphics do not count as instructional visuals.
