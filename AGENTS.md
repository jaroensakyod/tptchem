# CurioNest repository instructions

These instructions apply to the entire repository and survive model or agent changes.

## Required entry point

Before researching, authoring, revising, building, packaging, or auditing a CurioNest chemistry product:

1. Read `.agents/skills/curionest-complete-unit/SKILL.md` completely.
2. Read `product-quality-standard.md`, `product-lines/complete-unit-instruction-standard.md`, `product-lines/instructional-visual-policy.md`, `product-lines/complete-unit-quality-baseline.json`, and `docs/TPT-PRODUCT-RELEASE-CHECKLIST.md` completely.
3. Treat `product-lines/complete-unit-quality-baseline.json` as a locked minimum. Do not reduce a typography minimum, visual minimum, instructional component, assessment requirement, QA gate, or release gate unless the user explicitly requests that exact policy change. Record an approved change with a new contract version.

## Non-negotiable product rules

- Brand buyer-facing work exactly as `CurioNest` and use `© 2026 CurioNest · For classroom use only`.
- Build for U.S. Grades 9–10, American English, and US Letter unless the user explicitly changes the market.
- Teach before practice: `Engage -> Teach -> Model -> Guided Practice -> Independent Practice -> Formative Check -> Mixed Review -> Summative Assessment`.
- Use ChemPride only as a broad topic/workflow benchmark. Never copy or adapt its wording, questions, answers, images, screenshots, distinctive layout, or packet sequence.
- Do not use the local Chemistry 2e PDF for direct authoring or commercial adaptation.
- Never use CHEM P'M or CHEM_PM in buyer-facing work.
- Required instructional visuals must be documented free/open international-source assets that permit commercial reuse. Do not use AI-generated or code-drawn substitutes.
- Automated QA never authorizes publication. Keep the native-English, U.S. chemistry/science-teacher, and classroom dry-run gates visibly pending until real reviewers approve the final rebuilt files.

## Required finish sequence

Build from source, render every PDF page, inspect full-size pages and contact sheets, rebuild listing images from delivered pages, package exactly the declared buyer files, scan the exact final ZIP, record its SHA-256, run product QA, run repository QA, and synchronize the catalog and release evidence. Any content change reopens affected checks.
