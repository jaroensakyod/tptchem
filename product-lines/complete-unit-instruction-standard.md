# CurioNest Complete Unit Architecture

**Effective:** 2026-08-11  
**Market:** U.S. Grades 9-10 chemistry  
**Buyer format:** PDF unless an editable format is explicitly built and verified

## Required package architecture

Each chapter unit contains seven buyer files:

1. Complete Teacher File
2. Projectable Lesson Slides
3. Student Guided Notes and Practice
4. Unit Test A
5. Unit Test B
6. Teacher Guide and Answer Key
7. Rights and Sources

The upload kit also contains a preview PDF, three square listing images, listing copy, upload checklist, automated QA report, release evidence, Defender result, and SHA-256 manifest.

## Required lesson architecture

Each lesson uses two student pages and three projectable slides.

### Slide 1 / Student Page A - Engage and Teach

- learning target;
- short phenomenon, data, or prediction prompt;
- essential vocabulary;
- concise explanation with a functional visual when needed.

### Slide 2 / Student Page A - Model

- one complete worked example;
- visible reasoning steps;
- one check-for-understanding question.

### Student Page B - Practice and Check

- one guided item;
- three independent items with increasing transfer;
- one exit ticket;
- intentional writing or calculation space.

### Teacher support

- keyed answer for every item;
- rationale or accepted reasoning;
- likely misconception;
- exact repair move.

## End-of-unit architecture

- two-page mixed review after all lesson practice;
- two equivalent 20-item multiple-choice tests, Forms A and B;
- exactly four choices per item;
- complete rationale keys;
- no assessment-only concept;
- no verbatim reuse between forms;
- balanced coverage across learning targets.

## Release rule

A worksheet-only file cannot be named or listed as a complete lesson, core unit, or unit bundle. Missing instruction, modeled reasoning, supported practice, cumulative review, or assessment is a blocking defect—not a future enhancement.
